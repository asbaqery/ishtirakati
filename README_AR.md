# اشتراكاتي

موقع بسيط يعرّفك كم تدفع على اشتراكاتك بالشهر، ومتى ينخصم كل واحد.
مشروع Day 6 في دورة Web with AI (ثيم FinTech). الهدف اليوم: يشتغل، مو شرط يكون حلو.

## ميزات الـ MVP
1. تسجيل دخول بالإيميل، وكل مستخدم يشوف اشتراكاته بس.
2. إضافة اشتراك: الاسم، السعر بالدينار، شهري أو سنوي، تاريخ التجديد الجاي.
3. قائمة الاشتراكات مع التعديل والحذف.
4. المجموع الشهري بالدينار (السنوي ينقسم على 12).
5. التجديدات الجاية مرتبة حسب الأقرب مع كم يوم باقي. إذا مر تاريخ التجديد، الموقع يحسب التجديد اللي بعده تلقائيًا.

## الأدوات
- **React + Vite + TypeScript + Tailwind** للواجهة.
- **Supabase**: تسجيل الدخول (Auth) وجدول `subscriptions`.
- **Vercel** للنشر، و`vercel.json` يمنع خطأ 404 عند تحديث الصفحة.

## الأمان
- الجدول مقفول بـ RLS: كل مستخدم يقرأ ويضيف ويعدل ويحذف صفوفه هو بس.
- الزائر بدون تسجيل دخول ما عنده أي صلاحية على الجدول.
- `user_id` يتعبى من الجلسة داخل قاعدة البيانات، والمتصفح ما يرسله.
- المفتاح العام (publishable/anon) مسموح يكون في المتصفح لأن الحماية من RLS. المفتاح السري ما نستخدمه أبدًا.
- الأسعار أعداد صحيحة بالفلس عشان ما تصير أخطاء كسور.

## المتغيرات
| الاسم | وين يروح | الوصف |
|---|---|---|
| `VITE_SUPABASE_URL` | Vercel، Replit Secrets، `.env.local` | رابط مشروع Supabase |
| `VITE_SUPABASE_ANON_KEY` | Vercel، Replit Secrets، `.env.local` | المفتاح العام (publishable) |

## التشغيل محليًا
```bash
npm install
npm run dev
```
انسخ `.env.example` إلى `.env.local` وعبّي القيمتين.

## قاعدة البيانات
شغّل `supabase/migrations/20261111000000_subscriptions.sql` في SQL Editor بمشروع Supabase.

## الاختبارات
```bash
npm test
```

## حدود معروفة
- تأكيد الإيميل شغال، وخدمة الإيميل المجانية في Supabase ترسل بس لإيميلات أعضاء المشروع. عشان يسجل أي أحد، لازم تربط SMTP خاص (مثل Resend) أو تطفي «Confirm email» من Authentication.
- ما في تنبيهات قبل التجديد للحين، وهذي في الرؤية.
